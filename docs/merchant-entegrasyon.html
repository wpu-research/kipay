Kipay — Merchant Entegrasyon Örneği

Bu sayfa, sitenize ödeme widget'ını nasıl gömeceğinizi gösterir. Kullanıcı bilgileri (TC/ad/telefon) URL'de açık taşınmaz — opak token ile geçer.

Aşağıdaki kullanıcı bilgileri normalde sitenizde giriş yapmış üyeden gelir; burada demo için sabit.

Nasıl çalışır?

1) Sunucunuz ödeme oturumu oluşturur (KYC'yi burada verir), opak token alır:

POST https://www.kipayz.com/api/payment/session
Content-Type: application/json

{
  "merchant_id": "<MERCHANT_ID>",
  "user_id": "<üye id>",
  "identity_number": "<TC>",
  "first_name": "Ad", "last_name": "Soyad",
  "phone": "+90XXXXXXXXXX"
}
→ { "token": "<opak-token>" }   // 15 dk geçerli

2) Widget'ı bu token'la iframe/pencere olarak açarsınız:

https://www.kipayz.com/odeme/<MERCHANT_ID>?page=deposit&s=<token>

3) Sonucu postMessage ile dinlersiniz: pp-confirmed (kullanıcı yatırdım dedi), pp-close (kapatıldı). Kesin onay için Callback URL'inize gelen imzalı bildirimi esas alın.

⚠️ Üretimde token'ı sunucunuzda oluşturun (bu demo tarayıcıdan çağırıyor). Ayrıca site domain'iniz merchant "origin" ayarında tanımlı olmalı.
